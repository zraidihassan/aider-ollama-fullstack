## Description

Helps Claude categorize, prioritize, and respond to issues in Java projects.

---

- "Triage the last 10 issues"
- "Check recent bug reports"
- "Prioritize open feature requests"

---

## Examples

```
→ Categorizes, labels, suggests responses
```
